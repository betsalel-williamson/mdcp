# Sharded docs agent index (v0.5 draft)

## Sharded documentation

**MarkDown Context Protocol (MDCP)** keeps technical documentation in small **shard** files — one topic per `.md`. Guide manifests (`index.md`) define compile order. Monoliths and publish outputs are **generated**; shards are the source of truth.

MDCP applies to software repos, factory procedures, training curricula, and other durable technical knowledge. V1 stores shards in **git**; the content domain is separate from the transport.

**Not a monolithic `llms.txt` dump.** Use this short versioned index (`mdcp.v*.llms.txt`) plus on-demand shard reads.

## Getting started

**Step 0 (required for agents):**

```bash
npx @bwilliamson/mdcp-cli init --docs-root <docs-root>
```

**Step 1:** Ask the user — **defaults** (standard scaffold) or **augment** (map onto existing docs without deleting content)?

**Step 2:**

```bash
# Path A — greenfield / standard layout
npx @bwilliamson/mdcp-cli init --docs-root <docs-root> --mode default --preset code

# Path B — existing README or docs/ tree
npx @bwilliamson/mdcp-cli init --docs-root <docs-root> --mode augment --preset code
```

**Step 3:** `mdcp compile` then `mdcp check`.

Presets: `code`, `docs-site`, `operations`, `learning` (see `spec/extensions/arch-*`).

## Repo layout (archetype-aware template)

```text
docs/
  mdcp.v0.5.llms.txt       # this file — agent entrypoint
  mdcp.config.json         # compile wiring
  glossary/
    index.md
    *.md
  features/                # capabilities, procedures, or modules
    index.md
    *.md
  client/                  # optional — end-user or operator audience
  developer/               # optional — maintainer workflow
  extensions/              # optional — adoption plan, local rules
```

## Query context (prefer smallest unit)

1. `mdcp refs lookup "<topic>" --format json --config <config> --docs-root <docs-root>`
2. Read one shard `.md` from the lookup result
3. Broader export (last resort): `mdcp export --llm --stdout --config <config> --docs-root <docs-root>`

## Glossary

One term per shard under `glossary/`. Link `../glossary/index.md` from each guide manifest.

## Validation

Run `mdcp check` before trusting compiled output. Do not hand-edit generated compile output.

## Task prompts

Cached under `.caches/mdcp/prompts/` after init or fetch. Protocol 0.5 adds init-first bootstrap and augment prompts.

| Task | Cached path |

| Augment existing docs | `.caches/mdcp/prompts/augment-existing-docs.prompt.md` |
| Feature (docs + code) | `.caches/mdcp/prompts/feature-level-task.prompt.md` |

| Architecture / ADR | `.caches/mdcp/prompts/design-architecture-task.prompt.md` |

## Extensions

Optional packs under `spec/extensions/`: `prompts-*`, `arch-*`, `format-*` (C4, function points, ArchiMate). See [modeling framework compatibility](../../../docs/features/protocol/modeling-framework-compatibility.md).
