# MDCP extension pack format (DEPRECATED)

> **⚠️ DEPRECATION NOTICE:**
> The `mdcp.config.json` extension packs system and `.caches/mdcp/prompts/` dynamic fetching system have been deprecated in favor of **Agent Skills**.
>
> Please use the new `npx skills add betsalel-williamson/mdcp --skill mdcp` installation path instead. See the [Agent Skill documentation](../../docs/features/agent-skill.md) for details.
>
> **This directory and its contents will be removed in an upcoming release.** We are keeping these files temporarily to ensure backward compatibility for early adopters who have not yet migrated.

Normative layout and manifest schema for versioned extension packs under `spec/extensions/`.
