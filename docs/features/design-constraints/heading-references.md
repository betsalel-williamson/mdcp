# Heading references

No Pandoc IDs (`{#…}`) as the default authoring contract. [Heading slugs](../../glossary/heading-slug.md) use the GitHub algorithm on **compiled** output for headings MDCP recognizes. Part of [refs](../../glossary/refs.md).

Recognition is currently an ATX subset of GFM — setext and some ATX edge cases are not supported yet. See [GFM scope](./gfm-scope.md#headings).
