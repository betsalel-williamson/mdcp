# About this guide

**Audience:** coding agents and technical readers who need to understand what mdcp does — commands, design constraints, and migration from legacy tooling.

This is the **product** guide: capabilities and behavior of the tool itself. For how to contribute to this repository (setup, tests, changesets, releases), read the [Developer Guide](../developer/index.md).

Consumer adoption docs compile separately into npm package READMEs under `docs/client-cli/` and `docs/client-core/`.
