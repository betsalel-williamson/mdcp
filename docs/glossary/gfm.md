# GFM

**GitHub Flavored Markdown** — standard Markdown plus GitHub extensions (tables, task lists, fenced code).

MDCP’s format contract is authored GFM: **headings** and **links** (plus ordinary GFM constructs). Not Pandoc, LaTeX, or wikilinks. Not a chapter/section document model. Explicit Pandoc [xref](./xref.md) identifiers after headings are out of scope for authoring; see [Locale and language boundary](../features/design-constraints/locale-and-language.md).
