# Glossary

Shared acronyms and terms for all mdcp docs. Spell out on first use in a shard and link the short form here.

## GFM

**GitHub Flavored Markdown** — standard Markdown plus GitHub extensions (tables, task lists, fenced code). Not Pandoc, LaTeX, or wikilinks.

## Authored GFM

Shard markdown as written before compile — no preprocessor substitution or template conditionals. Compile hooks may transform it during assembly; see [Preprocessor / templating (out of scope)](../features/design-constraints.md#preprocessor-templating-out-of-scope).
