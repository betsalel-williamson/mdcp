# xref

An **xref** is a Pandoc-style explicit heading identifier — the brace-hash marker `{#…}` after a heading title.

MDCP does not use xrefs for authoring. Prefer [heading slugs](./heading-slug.md) from [GFM](./gfm.md) heading text. This repo’s Vale style `MDCP-Xref` warns authors to remove them. See [Locale and language boundary](../features/design-constraints/locale-and-language.md).
