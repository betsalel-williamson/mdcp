## 1.0.0 — first stable API release

This release graduates mdcp from `0.x` pre-release to **1.0.0**. Semver applies strictly from this version: breaking CLI, config, or compile-output changes require a major bump.

**Stable from 1.0.0:**

- `@bwilliamson/mdcp-core` — compile, validation, refs, and export APIs
- `mdcp` CLI — commands, flags, and exit codes
- `mdcp.config.json` — schema and defaults (`protocolVersion` `1.0.0.0`)
- Compile output — link rewriting, GitHub slug algorithm, broken-link markers, publish-relative paths

See the other changesets in this release batch for detailed entries.
